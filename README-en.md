## 🚀 Key Features
- **Real Script Blocking:** Holds back the injection of Google Analytics, Meta Pixel, and other trackers until the user clicks "Accept All".
- **Visual Customization:** Adjust the banner color and text from a clean and intuitive admin panel in WP Admin.
- **Zero Dependencies:** Written in pure PHP and Vanilla JS. Zero negative impact on your website's loading speed.
- **Tabbed Panel:** Easy-to-use interface, separated into Appearance, Scripts, and System Status options.

## 🛠️ Installation
1. Download this repository as a `.zip` file by clicking the green **Code** -> **Download ZIP** button.
2. Go to the **Plugins** section in your WordPress dashboard and click **Add New** -> **Upload Plugin**.
3. Select the downloaded `.zip` file and click **Install Now**.
4. Activate the "MiaCodeWEB GDPR Cookie Blocker" plugin.

## ⚙️ Quick Setup
1. In the left sidebar of your WordPress dashboard, look for the shield icon **GDPR Cookies**.
2. In the **Appearance** tab, customize the colors and text to match your brand identity.
3. In the **Scripts (Blocking)** tab, paste your third-party `<script>` tags. That's it! All tracking will be paused until legal consent is received.
